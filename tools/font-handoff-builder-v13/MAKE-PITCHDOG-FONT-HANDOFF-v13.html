Known source detail

Eyebrow installs as “Untitled”.

The accepted binaries currently carry Untitled as their internal family name. The 350/400 static anchors also collide by full and PostScript name. Prefer the variable Eyebrow; install only one static Eyebrow weight/posture at a time. The web CSS alias is safe.

Canonical use

Variable first.

  • Web uses variable WOFF2.
  • Apps and designers use variable TTF.
  • Static anchors are compatibility fallbacks.
  • Never install variable and static duplicates together.
