# Accessibility QA

## Required tests

- Semantic heading outline independent of visual role
- 200% browser text resize
- 320 CSS px effective width and reflow
- WCAG text-spacing overrides
- Keyboard focus and visible focus rings
- Coarse-pointer target size
- Reduced motion
- Forced colours
- Screen-reader reading order
- Right-to-left content
- CJK content
- Long German expansion
- Font blocked and font failed states
- Zoom after fonts load
- Motion geometry after fonts load and after resize

## Typography constraints

- No essential line clamp
- No fixed-height text containers
- No pure viewport-unit font sizes
- No placeholder-only form labels
- No colour-only link or state distinction
- No synthetic Head italic
- No hidden semantic text behind canvas-only or WebGL-only rendering
