# Documentation

Find the document for the job in front of you. Values always come from `tokens/pitchdog.system.tokens.json`; these documents explain them.

## Start

| Document | Read it when |
| --- | --- |
| [TYPE-SYSTEM-README.md](TYPE-SYSTEM-README.md) | You are new here and want the governing decisions on one page |
| [SPECIFICATION.md](SPECIFICATION.md) | You need the full behaviour of every family, layer and role |
| [USING-IN-PROJECTS.md](USING-IN-PROJECTS.md) | You are installing the system in an app, a submodule or a design tool |
| [IMPLEMENTATION.md](IMPLEMENTATION.md) | You want markup examples for each layer, or need to regenerate derived files |
