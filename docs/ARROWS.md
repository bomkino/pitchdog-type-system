# Arrow system

## Repertoire

`← ↑ → ↓ ↔ ↕ ↖ ↗ ↘ ↙ ↩ ↪`

All twelve glyphs are native to Head, Head Alt, Body, Body Alt and Eyebrow in FontBlind v13.

## Roles

- Inline: inherit the surrounding Body typography.
- UI: Eyebrow 600, width 100, italic 0.
- Display: Head 600, italic 0.

## Accessibility

When an arrow repeats a written action, mark it `aria-hidden="true"`. When the arrow is the only visible content, give the control an accessible name that states the action. Do not rely on direction alone for destructive, unusual or culturally ambiguous actions.

## Semantics

- `←` — previous, back, earlier
- `↑` — up, move upward, top
- `→` — next, continue, external direction
- `↓` — down, reveal, expand
- `↔` — horizontal relationship or resize
- `↕` — vertical relationship or resize
- `↖` — north-west direction
- `↗` — north-east or external-launch direction
- `↘` — south-east direction
- `↙` — south-west direction
- `↩` — return, enter, undo only when context names it
- `↪` — forward return or redo only when context names it
