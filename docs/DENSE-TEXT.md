# Dense text and long-form reading

The website contains long beliefs, process instructions, FAQs, pricing tables, testimonials and service inventories. The system treats these as primary content.

## Reading defaults

- `body.reading`: 19–21 px equivalent, Body 400, 1.58 line-height, 64ch
- `body.default`: 17–19 px equivalent, Body 400, 1.52 line-height, 68ch
- `body.compact`: 16–17 px equivalent, Body 400, 1.45 line-height, 72ch
- Inline strong: Body 600
- Body italic: authentic Body Italic 400

## Dense layout rules

1. Do not shrink below the compact role to make a fixed card fit.
2. Let cards grow vertically.
3. Use productive Body headings inside dense grids.
4. Use Eyebrow for data, not explanatory paragraphs.
5. Separate paragraphs through space, not first-line indent in interface-like content.
6. Use columns only for sustained editorial copy at sufficiently wide viewports.
7. Collapse columns before line measure becomes narrow.
8. Avoid balancing paragraphs.
9. Test at 200% text and with WCAG text-spacing overrides.
10. Never line-clamp essential descriptions, FAQs or testimonials.
