# Governance

## Source of truth

`tokens/pitchdog.system.tokens.json` is canonical.

## Prohibited in component CSS

- raw brand-family names
- arbitrary `font-size`
- unapproved weight or width values
- raw Head `ital` values outside 0/1 except a documented transition
- arbitrary line-height or tracking
- weight animation
- font synthesis

## Exceptions

Every exception records:

1. the problem
2. why no role works
3. affected components
4. content and language risks
5. temporary or permanent status
6. removal condition

## Change control

Typography changes are versioned because they can alter line count, card height, scroll geometry, animation timing, export composition and localisation.
