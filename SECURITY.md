# Security

This repository ships fonts, CSS, JSON tokens, static HTML and small Python maintenance scripts. It runs no service and stores no user data.

## Reporting a vulnerability

Use GitHub's private reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. If that option is not available, open an issue that says you have a security report and asks for a private contact, without including any details.

Useful reports include a malicious or malformed font file, a script that can write outside the repository, a checksum or provenance check that can be bypassed, or a script-injection path in the specimen HTML.

Please do not publish details until a fix has been released.
